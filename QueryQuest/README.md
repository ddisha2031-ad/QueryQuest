# QueryQuest — Customer Support & Operations Analytics Platform

QueryQuest is a GitHub-ready analytics project that turns a synthetic customer-support dataset into decision-ready operational insight using SQL, Python, SQLite, Streamlit, and Plotly.

## Business problem
Management needs to understand ticket volumes, resolution speed, SLA compliance, backlog aging, workload balance, and customer satisfaction.

## Key features
- Reproducible synthetic dataset: 15,000 tickets (seed 42), with documented data-quality issues.
- Normalized SQLite database: tickets, agents, teams, customers, SLA policies.
- 38 executable SQL business queries with CSV exports.
- Multi-page Streamlit dashboard, including a safe SQL Query Explorer.
- Jupyter EDA notebook, pytest test suite, data dictionary, metric definitions, and business report.

## Dataset disclosure
All companies, agents, customers, teams, and tickets are **fictional/synthetic**, generated by `src/data_generator.py` with seed 42.

## Installation
```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate
pip install -r requirements.txt
```

## Build database and run analysis
```bash
python scripts/setup_database.py
python scripts/run_analysis.py
python scripts/generate_report.py
```

## Run dashboard
```bash
streamlit run app.py
```

## Run notebook
```bash
jupyter notebook notebooks/support_operations_eda.ipynb
```

## Run tests
```bash
pytest -q
```

## Example findings from executed outputs
- 15,000 total tickets; 3,095 open/pending; 11,905 resolved.
- Average resolution time: 1,361 minutes; average CSAT: 3.86/5.
- Critical-priority SLA compliance: 50.04%, the lowest of all priorities.
- 2,936 reopened-ticket events were recorded.

## Troubleshooting
- `ModuleNotFoundError: src` — run commands from the project root.
- Dashboard does not open — confirm Streamlit is installed and port 8501 is available.
- Database missing — run `python scripts/setup_database.py`.
